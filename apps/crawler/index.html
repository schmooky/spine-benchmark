Pixi Crawler

A drop-in performance crawler for PixiJS 8

Crawler instruments the renderer to break every frame down into where the milliseconds go - CPU pre-work, pixi build / transform / execute, Spine, and true GPU time - plus device-invariant workload counters. It is added to any app in one call: mountCrawler(app).

This scene is a swarm of moving sprites with a filtered, masked panel, just so the HUD has something to chew on.
