# Design source files

Penpot source files for the project's visual design. These are
committed as the canonical design truth - the deployed site, README
screenshots, and published package assets should all trace back to
here.

- [`redesign.pen`](./redesign.pen) - in-progress redesign explorations
- [`spine-benchmark.pen`](./spine-benchmark.pen) - current site design

Open with [Penpot](https://penpot.app) (free, open source) or the
Penpot desktop app. Export PNGs / SVGs into `docs/media/` when
capturing assets for the README.
