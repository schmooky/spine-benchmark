pixi-crawler - профайлер производительности для Pixi 8

Встраиваемый инструмент измерений: покадровый разбор того, куда уходят миллисекунды (CPU-подготовка, pixi build / transform / execute, Spine, реальное GPU-время), счётчики нагрузки, HUD и телеметрия. Подключается к любому приложению одним вызовом.

Установка

pixi.js - это peer-зависимость. Крайне важно, чтобы версия pixi в приложении и в пакете совпадали точь-в-точь: крокер патчит прототипы pixi, и при разных версиях он пропатчит не тот граф. 

npm install @spine-benchmark/pixi-crawler

Быстрый старт

Один вызов mountCrawler(app). По умолчанию показывает HUD и сам снимается с приложения по событию pagehide. 

import { Application } from "pixi.js";
import { mountCrawler } from "@spine-benchmark/pixi-crawler";

const app = new Application();
await app.init({ background: "#101317", resizeTo: window });

// HUD виден, авто-dispose на pagehide
const crawler = mountCrawler(app);

// headless (без HUD) + телеметрия
const headless = mountCrawler(app, { hud: false, telemetry: { sink } });

mountCrawler принимает Pixi-Application либо любой объект с полями { renderer, ticker }, а вторым аргументом - конфигурацию (см. ниже) плюс флаг autoDispose (по умолчанию true).

Полный контроль

Если нужен полный жизненный цикл - создавайте экземпляр напрямую и управляйте attach / detach / dispose сами. 

import { Crawler } from "@spine-benchmark/pixi-crawler";

const crawler = new Crawler({
  targetFrameMs: 1000 / 60,   // бюджет кадра для нормировки полос HUD
  hud: !import.meta.env.PROD,
  spineProfile: { enabled: true },
  telemetry: { sink, sampling: { windowMs: 5000 }, rawFrames: "on-overrun" },
});

crawler.attach(app.renderer, app.ticker);

window.addEventListener("pagehide", () => void crawler.dispose());

Контракты и ограничения

Тикер приложения не должен быть Ticker.shared. Приложение обязано владеть собственным тикером: на общем тикере Spine конфликтует с крокером. Это единственная жёсткая несовместимость.
  • Версия pixi должна совпадать точь-в-точь - крокер патчит прототипы pixi; несовпадение версий приведёт к патчу не того графа.
  • gpuMs = null на Safari / iOS - там нет расширения EXT_disjoint_timer_query_webgl2. CPU-измерения при этом работают; крокер сам отбрасывает «дизъюнктные» (недостоверные) показания GPU-таймера.
  • dispose() / detach() восстанавливают пропатченные методы (в т.ч. TextureSource.prototype.unload). Вызывайте один из них при размонтировании.
  • Измерения - это накладные расходы. Держите включённым только то, что реально читаете (см. конфигурацию).

Ручной цикл рендера

Если приложение рисует само (тикер остановлен, свой requestAnimationFrame), оборачивайте каждый кадр вручную. На работающем тикере эти вызовы не нужны - attach() уже привязал границы кадра к тикеру. Смешивать два режима нельзя (двойной учёт). 

app.ticker.stop();

function frame() {
  crawler.frameStart();
  // ... продвинуть сцену, затем отрисовать
  app.render();
  crawler.frameEnd();       // сбрасывает один FrameRecord
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);

Конфигурация

Все поля CrawlerConfig опциональны; каждое включает свою подсистему.

ПолеПо умолч.Назначение
hudoffПоказать DOM-оверлей HUD. Через mountCrawler - on.
targetFrameMs1000/60Бюджет кадра в мс: по нему HUD нормирует полосы и красит статус.
bufferSize600Размер кольцевого буфера кадров (сколько последних FrameRecord хранить).
enableGpuTimingonРеальное GPU-время кадра через EXT_disjoint_timer_query (gpuMs).
deepRenderSplitonРазбивка CPU-времени рендера по фазам (build / transform / execute / ...).
filterProfileonТайминг фильтров (push / apply / pop) и число проходов.
textureTrackingonЗагрузки / выгрузки текстур, байты, число активных на GPU.
spineProfileoffПофазный разбор Spine. Патчит методы Spine - не включайте, если сами измеряете время внутри spine.update().
pipeProfileoffТайминг каждого вызова render-pipe. Самые тяжёлые накладные расходы.
workloadCostonОткрытая device-независимая мера нагрузки (произв., читается по запросу).
gpuCostonОткрытая мера GPU-тяжести (fill-footprint + фильтры).
selfProfileoffПофункциональный self-time через W3C JS Self-Profiling (нужен заголовок Document-Policy: js-profiling, только Chromium).
memoryProfileoffПамять процесса через measureUserAgentSpecificMemory() (нужна cross-origin isolation).
telemetryoffПериодическая отправка агрегатов в ваш sink (см. ниже).

Чтение измерений

Крокер не требует HUD - можно читать кадры напрямую и строить свою панель.

const f = crawler.getLastFrame();     // последний FrameRecord (или undefined)
f.gpuMs;                              // реальное GPU-время, мс (null без таймера)
f.counters.drawCalls;                // драв-коллы
f.counters.verticesDrawn;            // вершины/индексы
f.counters.stencilMaskPasses;        // stencil-маски
f.counters.renderTargetSwitches;     // смены render-target
f.renderSplit?.updateRenderablesMs;  // CPU-фаза рендера, мс

crawler.getFrames();               // весь кольцевой буфер
crawler.getWorkloadCost();        // открытая мера нагрузки + узкое место
crawler.getGpuCost();             // открытая мера GPU-тяжести
crawler.getWorstFrame();          // худший кадр + дамп сцены

// GPU-запросы приходят на 1-3 кадра позже; в конце окна измерений слейте их:
await crawler.flushPendingGpu();

Телеметрия

Задайте telemetry.sink - крокер будет слать агрегированные батчи (перцентили по окну). Отправка «fire-and-forget»: крокер не ждёт ответа, ошибки ловит и логирует. Транспорт - ваш. 

const sink = {
  send(batch) {
    navigator.sendBeacon("/telemetry", JSON.stringify(batch));
  },
};

const crawler = new Crawler({
  telemetry: {
    sink,
    sampling: { windowMs: 5000 },   // частота флаша, мс
    rawFrames: "on-overrun",        // сырые кадры только на просадках
  },
});
crawler.attach(app.renderer, app.ticker);

// помечайте текущую сцену для атрибуции корпуса измерений
crawler.setTelemetryLabel("bonus-game");

HUD и темы

HUD - приглушённая, нейтральная панель поверх сцены (без «неона»). Клик по «-» сворачивает её в бейдж FPS. Вся палитра задаётся CSS-переменными --sbc-* на корне #sbc-crawler - переопределите пару переменных и получите свою тему. 

import { mountCrawler } from "@spine-benchmark/pixi-crawler";
mountCrawler(app);

/* например, тёплая тема - в вашем CSS: */
/* #sbc-crawler.sbc-hud { --sbc-bg: rgba(22,19,17,.95); --sbc-accent: #c2a878; } */

Запись сессии

Кадры можно записать и сохранить в JSON, чтобы позже воспроизвести в инспекторе (кнопки записи/сохранения/загрузки есть и в HUD). 

crawler.startRecording();
// ... воспроизведите проблемный сценарий ...
crawler.stopRecording();
const recording = crawler.getRecording();   // { version, frames, ... } -> сериализуйте в JSON
pixi-crawler - профайлер производительности для PixiJS 8. Публичный API: mountCrawler, Crawler. Требует Pixi 8 (peer-зависимость, версия точь-в-точь) и тикер приложения, отличный от Ticker.shared.
